# SlideScribe for Panopto

**Turn Panopto lecture recordings into study notes: every slide, plus a timestamped transcript of what the lecturer said on each one.**

SlideScribe is a userscript that adds a small export panel to Panopto's video viewer. One click gives you:

- **Every slide** from the recording's Contents tab, as a full-resolution image with its text
- **A transcript**, taken from Panopto's own captions when the lecture has them, or generated by [Whisper](https://github.com/openai/whisper) running **locally in your browser** when it doesn't
- **Slides and transcript lined up**, so each slide is followed by what was said while it was on screen

Nothing is uploaded to any server. Audio is transcribed on your own machine.

---

## Output

| File | What it is |
|---|---|
| `<lecture> - notes pack.html` | A single self-contained page with slide images, slide text and the transcript under each slide. It opens offline and prints to PDF. |
| `<lecture> - transcript.md` | The same content as plain Markdown, ready to paste into an AI assistant, Notion, Obsidian and similar tools. |
| `<lecture>.mp4` *(optional)* | The lecture audio, via the "Download audio only" button. |

Example Markdown output:

```markdown
## Slide 2 [0:09] TCP/IP Protocol Suite

**Slide text:**
- TCP/IP Protocol Suite
- (Forouzan, 2013)

**Lecturer:** As shown in this slide, TCP/IP protocol stack defines two protocols,
a transport layer, TCP and UDP. We covered TCP in lectures four and five...
```

## Compatibility

### Browsers

| Browser | Works? | Transcription speed | Notes |
|---|---|---|---|
| **Google Chrome** 138+ (Windows, macOS) | ✅ Yes, **tested** | Fast (WebGPU) | You must turn on "Allow User Scripts" (see install step 2). |
| **Microsoft Edge** 138+ | ✅ Expected | Fast (WebGPU) | Chromium-based, so it has the same "Allow User Scripts" step as Chrome. |
| **Brave / Opera / Vivaldi** | ✅ Expected | Fast (WebGPU) | Chromium-based. Use your browser's extensions page for the user-scripts toggle. |
| **Firefox** (Windows) | ✅ Expected | Fast on 141+ (WebGPU), slow on older versions | No extra toggle is needed. |
| **Firefox** (macOS / Linux) | ✅ Expected | Fast where WebGPU is available, otherwise slow CPU mode | WebGPU support varies by OS and GPU. |
| **Safari** 26+ (macOS) | ⚠️ Probably | Fast (WebGPU) | Needs a Safari userscript manager. Untested. |
| **Chrome on Linux** | ✅ Expected | Depends on GPU driver | WebGPU support varies on Linux. CPU mode works as a fallback. |
| **Phones / tablets** | ❌ Not supported | — | Whisper needs more memory than mobile browsers reliably allow. |

**Without WebGPU** the script switches to CPU (WebAssembly) mode on its own. It still works, but a 1-hour lecture can take 20–40+ minutes instead of about 5. Slides and existing captions are just as fast either way.

To check whether your browser has WebGPU, open the browser console (F12) on any page and run `!!navigator.gpu`. It returns `true` if WebGPU is available.

### Panopto sites

The script runs automatically on the standard Panopto cloud domains:

- `*.panopto.com`, which also covers US, Canada, Asia-Pacific and other `*.ap.panopto.com`-style regional sites
- `*.panopto.eu`, which also covers `*.cloud.panopto.eu` European sites such as Leeds Beckett's

**If your university uses its own domain** (for example `replay.youruni.ac.uk`), the script won't appear there automatically. Add a `@match` line for your domain to the script header:

```js
// @match        https://replay.youruni.ac.uk/Panopto/Pages/Viewer.aspx*
```

### Lecture types

| Recording | What you get |
|---|---|
| PowerPoint captured by Panopto (slides in Contents tab) | ✅ Slides and transcript |
| Lecture with Panopto captions turned on | ✅ Uses the official captions, so transcription is instant |
| Video or screen-capture only, with no Contents tab | ⚠️ Transcript only; there are no slide images to pull |

## Install

1. **Install a userscript manager.** [Tampermonkey](https://www.tampermonkey.net/) is the easiest choice.
2. **Chrome / Edge / Brave only: allow user scripts.** Since Chrome 138, extensions can't run userscripts until you allow it:
   - Right-click the Tampermonkey icon and choose **Manage extension**, then turn on **Allow User Scripts**.
   - If you don't see that option, open `chrome://extensions` and turn on **Developer mode** (top right).

   This step is the most common reason the panel doesn't appear.
3. **Install the script.** Open [`slidescribe.user.js`](../../raw/main/slidescribe.user.js) (the raw file) and your userscript manager will offer to install it. You can also create a new script in the manager and paste the file's contents.
4. **Open any lecture.** The **SlideScribe** panel appears in the bottom-right corner.

## Usage

1. Open a lecture in Panopto (`.../Panopto/Pages/Viewer.aspx?id=...`).
2. Pick a Whisper model:
   - **base.en (fast)** is the default and handles clear lecture audio well.
   - **small.en** is more accurate with accents and technical vocabulary, but about 3× slower.
3. Click **Export slides + transcript** and keep the tab open until it says **Done**.
4. The two files land in your Downloads folder.

The first run downloads the Whisper model (roughly 100–400 MB depending on choice). Your browser caches it, so later runs start straight away.

### Typical timing (Chrome, WebGPU)

| Lecture length | base.en | small.en |
|---|---|---|
| 10 min | ~1 min | ~3 min |
| 1 hour | ~5 min | ~15 min |

The 10-minute base.en figure was measured; the rest are estimates and depend on your GPU. Lectures that already have Panopto captions take seconds whatever their length.

## How it works

SlideScribe uses the same data the Panopto viewer itself loads:

1. **Lecture info:** `DeliveryInfo.aspx` returns the session name, the slide timeline (title, text, timestamp of every Contents entry) and the audio stream.
2. **Slides:** Panopto logs every PowerPoint animation step as its own Contents entry, so one slide can appear five or more times. SlideScribe groups the steps by slide number and keeps the last, fully revealed build. In testing, a lecture with 34 Contents entries came out as its 8 real slides.
3. **Images:** each slide is fetched at full resolution from `Image.aspx` and embedded in the HTML file.
4. **Transcript:** the script uses Panopto captions if they exist. Otherwise it downloads the lecture's audio-only MP4, decodes it to 16 kHz in the browser, and transcribes it in 5-minute blocks with [Transformers.js](https://huggingface.co/docs/transformers.js) Whisper models, using WebGPU when available and WebAssembly otherwise.
5. **Alignment:** each transcript line is placed under the slide that was on screen when it was spoken.

## Troubleshooting

| Problem | Fix |
|---|---|
| **Panel doesn't appear** | Turn on "Allow User Scripts" or Developer mode (install step 2), then reload the lecture tab. Check that the script is enabled in your manager's dashboard. |
| **Panel doesn't appear on my uni's site** | Your university may use a custom domain. Add a `@match` line (see [Panopto sites](#panopto-sites)). |
| "No downloadable audio stream found" | That recording doesn't offer an audio-only stream. Slides still export through the button, but the transcript can't be generated. |
| Transcription is very slow | Your browser has no WebGPU, so it's running on the CPU. Try a recent Chrome or Edge. |
| Transcript is wrong on technical words | Switch to **small.en**. |
| Tab crashes on a very long lecture (2h+) | Close other tabs to free memory, or use **base.en**. |

## Responsible use

SlideScribe is meant for **personal study of recordings you already have access to**. It doesn't bypass sign-in or permissions; it only uses what your own browser session can already load.

- Lecture recordings and slides usually belong to your institution or lecturer. **Don't redistribute** exported files.
- Check your university's policy on recordings. Some modules have specific rules.
- Lecturers can disable the audio-only stream. If a recording doesn't offer it, SlideScribe can't transcribe it.
